HOW TO UPLOAD A JAVA WORLD
--------------------------
1. LOCATE YOUR MINECRAFT SAVES FOLDER:
     WINDOWS : %appdata%\.minecraft\saves
     MAC     : ~/Library/Application Support/minecraft/saves
     LINUX   : ~/.minecraft/saves
2. COMPRESS YOUR WORLD FOLDER TO .ZIP:
     - OPEN THE 'saves' FOLDER.
     - RIGHT-CLICK ON YOUR WORLD FOLDER.
     - SELECT 'COMPRESS TO ZIP FILE' (OR 'SEND TO -> COMPRESSED FOLDER').
     - MAKE SURE level.dat IS DIRECTLY INSIDE THE ZIP ROOT (NOT DOUBLE-NESTED).
3. OPEN THE [ UPLOAD ] TAB ABOVE.
4. DRAG & DROP YOUR .ZIP FILE OR CLICK [ BROWSE... ].
5. CLICK [ START UPLOAD ] AND WAIT FOR COMPLETION.


HOW TO USE A DOWNLOADED JAVA WORLD
----------------------------------
1. DOWNLOAD THE .ZIP FROM THE FILES TAB.
2. UNZIP IT. YOU GET A FOLDER (level.dat, region\, ...).
3. PUT THAT FOLDER IN:
     WINDOWS : %appdata%\.minecraft\saves
     MAC     : ~/Library/Application Support/minecraft/saves
     LINUX   : ~/.minecraft/saves
4. START MINECRAFT JAVA WITH THE MATCHING VERSION (see MC VERSION column)
   AND OPEN THE WORLD UNDER SINGLEPLAYER.

NOTES
-----
* OPENING A WORLD IN AN OLDER VERSION THAN IT WAS SAVED IN CAN BREAK IT.
* KEEP A BACKUP COPY BEFORE OPENING.
* ONLY THE UPLOADER CAN DELETE THEIR OWN FILES.
